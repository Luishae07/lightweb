Light.web

A small web of its own. Sites have names like blog.nerd, pages are written in one simple language, and anyone can host a site from a folder.

What it is

NamesA site is found by name, like search.cool. A name service (the SFW) tells the browser where the site lives.
One page languageSFAGHC (.sf files) holds structure, layout, style, state and logic in a single file. No closing tags.
Your own sitelwserve serves a folder, opens a free tunnel for you, and registers your name. Home connection is enough.

The browser (Mac)

For Apple Silicon and Intel. One line installs it and puts Light.web.app in Applications:

curl -fsSL https://raw.githubusercontent.com/Luishae07/lightweb/main/install-app.sh | sh

Open it, press Cmd+L and type a name, for example blog.nerd, sfadocs.nerd or search.cool.

Host a site

Install lwserve (Linux and macOS):

curl -fsSL https://raw.githubusercontent.com/Luishae07/lightweb/main/install.sh | sh

Make a folder with a front page, index.sf:

page "Hello"
  document_description_crawl = "My first Light.web page"
  column gap=16
    h1 "Hello from my site"
    text "It works."

Start it. -bore opens a free public tunnel by itself and registers your name:

lwserve -name mysite.nerd -bore -dir ./pages

Pages stay encrypted all the way; the relay only passes the traffic on. Windows: download lwserve-windows-amd64.exe from the releases.

Help the name service

Anyone can run a read-only mirror of the name service, so names can still be looked up when the main one is away. A mirror cannot change where a name points: every record carries the site owner's signature, and the browser checks it. The browser reads nodes.txt every five minutes and uses the quickest node.

sfw -mirror <main SFW address> -listen :7001

Add your public address to nodes.txt with a pull request. Details are in the README.

Learn the language

The SFAGHC guide, with examples, is on the wiki, and as a site inside Light.web itself: open sfadocs.nerd in the browser. Big files can be offered for download with a single line, download_hosted_file=/thing.zip.
